## 完成：MyStokView 持仓管理应用（CodeBuddy Agent SDK 全栈）

基于 CodeBuddy Agent SDK 模板架构（Express + SSE + React/Vite/TDesign + SQLite）搭建完成。

### 技术要点
- 后端 `server/`：db.ts（better-sqlite3，holdings/quote_cache/chat_messages 三表，seed 7 只持仓）、market.ts（westock CLI 封装）、agent.ts（Agent SDK）、index.ts（REST + SSE，端口 3001）
- 前端 `src/`：TDesign 侧边栏（我的持仓 / 持仓管家）、概览卡、可编辑持仓表格、新增对话框（名称搜索自动填代码）、60s 自动刷新、授权 banner、SSE 对话页
- 前端 Vite 5173 端口，/api 代理到 3001

### 关键坑与解法（重要）
1. **westock quote 无 --json**：输出为 markdown 表格，后端用 parseMarkdownTable 解析；未授权时输出含 `AUTH_REQUIRED:<url>`，回退 SQLite 缓存价
2. **@tencent-ai/agent-sdk CLI 默认端口 58145 与 WorkBuddy 桌面端冲突**：报 `listen EADDRINUSE 127.0.0.1:58145`。解法：每次 query 前用 net 模块找空闲端口，通过 `options.extraArgs: { port: String(port) }` 传给 CLI（extraArgs 会拼成 --port）
3. **CLI 认证**：SDK spawn 的 CLI 不复用 WorkBuddy 桌面端登录态，需用户执行 `npx codebuddy login` 或配置 `CODEBUDDY_API_KEY`；agent.ts 已内置中文引导，前端流式展示
4. **TDesign Table 无 footer 属性**：合计行改为表格下方独立 div
